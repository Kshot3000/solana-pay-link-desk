    How it works
    
    
      
      
    1. Link. The desk builds a standard Solana Pay transfer request URL
      (solana:<recipient>?amount=…&spl-token=…&reference=…) — the same format wallets already understand.
      2. 
      
    2. QR. The URL is rendered as a QR code locally in your browser (vendored MIT QR library; nothing is uploaded).
      3. 
      
    3. Verify. Verification queries a public Solana RPC for transactions carrying the link's reference key and compares pre/post balances: the recipient must have gained at least the requested amount of the requested token in a successful transaction.
      4. 
    
    
    
    No server, no sign-up, no wallet connection, no signing — the desk can never move funds.
    Always double-check the recipient address in your wallet before paying.
